# 02 – KW Command: the system of record

Command is where every contact, every deal, every touch, and every task lives. If it is not in Command, it did not happen.

| File | What it covers |
|---|---|
| `database-architecture.md` | Tags, sources, Met / Haven't Met, custom fields, saved filters, import and hygiene rules |
| `opportunities-pipeline.md` | The three pipelines (Seller, Buyer, Investor), stage definitions, what must be true to move a stage, and what each stage triggers |
| `command-setup-checklist.md` | One-time setup, in order, with who does it |

SmartPlan step-by-step copy lives in `04-AUTOMATIONS/command-smartplans/`. Zaps that write into Command live in `04-AUTOMATIONS/zaps/`.

Note on Command features: Command changes often. Where this repo says "verify in Command", open the feature and confirm the field or trigger exists in your account before building around it. Kelle (KW's AI assistant inside Command) can answer "how do I" questions about Command itself.
