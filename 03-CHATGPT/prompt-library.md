# Prompt Library

Read `/00-START-HERE/conventions.md` first. Every prompt below is meant to be pasted into the named GPT (or the `Charles Brewer Real Estate OS` Project when no GPT fits). Replace bracketed placeholders before running. Every output is a draft: ChatGPT drafts, a human approves, Command sends.

How to use: copy the code block, fill the brackets, paste into the GPT, read the result, edit, then paste into Command, the social scheduler, or Slack for approval. Log any prompt that produced a bad result in `#ops` for the monthly review.
