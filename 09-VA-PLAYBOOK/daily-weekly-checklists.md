# VA Daily, Weekly, and Monthly Checklists

Read `README.md` in this folder first. Times are [MARKET] local time. If a block runs long, the lead inbox and the 5-minute standard always win over everything else.

## Daily checklist by time block

### 8:00  Lead inbox and speed-to-lead follow-up (30 min)
- [ ] Open `#leads`. Every alert since 5pm yesterday: confirm a human response is logged in the thread ("called", "texted", "replied"). If not, call now, then log.
- [ ] Overnight leads: send the human reply (from the Z-02 drafts, after review) by 8:15. The standard for after-hours leads is first thing this morning.
- [ ] Check Zapier for errors on Z-01, Z-03, Z-05, Z-14; re-run or process manually per `SOP-01`.
- [ ] Meta Ads Manager leads export (if Z-03 has errored) and Google Voice missed calls (if Z-13 is not built).
- [ ] Command inbox: texts and emails replied to leads and clients; log notes.
- [ ] Yesterday's leads: tags correct, `SP-Speed to Lead` running, Opportunity exists (`SOP-01` step 8).

### 8:15  Daily huddle with Charles (15 min)
- [ ] Agenda per README: leads, sends waiting on Charles, due today, calendar prep, one blocker.

### 8:30  Command tasks due (45 min)
- [ ] Open Command Tasks filtered to VA, due today. Work them in this order: client-facing sends awaiting approval, SmartPlan send tasks (fill placeholders, post drafts for approval, send approved ones), milestone tracker items, everything else.
- [ ] Charles's tasks due today: post a one-line reminder list in `#ops`.
- [ ] Monday only: confirm Z-08 created Weekly Seller Report tasks; if not, create them from `Active Listings`.
- [ ] Friday only: confirm Z-15 created Project Update tasks for every Rehab deal.

### 9:00  Social posting (45 min)
- [ ] Publish or confirm today's scheduled posts (`SOP-04`); approve any Z-07 stage post that Charles approved in `#listings`.
- [ ] Reply to every comment and DM from the last 16 hours; log any lead via the DM Lead Capture form.
- [ ] Post stories per the weekly story sequence.
- [ ] Tomorrow's post: draft or confirm it is scheduled.

### 10:00  Listing coordination (90 min)
- [ ] Every listing in `Active Listings`: what is due today per its launch checklist or SmartPlan (`SOP-03`)?
- [ ] Vendor confirmations for the next 3 days (photographer, 3D, sign, cleaner, stager).
- [ ] Showing feedback received in the last 24 hours: relay to Charles for the seller (never send feedback to a seller without Charles reading it).
- [ ] Contracts: milestone tracker check for the next 5 days (`SOP-07`); send logistics reminders the VA is allowed to send.
- [ ] Deal Board: update any stage changes; file contractor invoices in the deal folder.
- [ ] Open house this week: promo and sign-in form prep (`SOP-06`).

### 12:00  Lunch. Phone on for `#leads` only.

### 1:00  Database hygiene (30 min)
- [ ] Yesterday's new contacts: exactly one type, one relationship, one source tag (`SOP-02`).
- [ ] Dedupe: search new contacts by phone and email.
- [ ] Reply notes from SmartPlan emails logged; anything that sounds like a move flagged to Charles.
- [ ] Ten contacts per day: fill missing birthday, home anniversary, address, or spouse fields from what you can find in email history and notes.

### 1:30  Flex block (90 min)
- Monday: seller report drafts (see 3:00). Tuesday: schedule next week's social. Wednesday: marketing kit QA, video captions. Thursday: 33 Touch and 12 Direct prep for next month, review requests. Friday: scorecard (`SOP-10`), project update drafts.

### 3:00  Seller reports (Monday) / partner updates (Friday)
- [ ] Monday: every seller report approved by Charles is sent from Command by 3pm; log send time in `Seller Report Log` (`SOP-05`). Chase any approval still pending at 2:30.
- [ ] Friday: every partner Project Update approved by Charles is sent from Command by 3pm; log in `Project Update Log`.
- [ ] Other days: use this block for Command SmartPlan send tasks and follow-ups.

### 4:00  Lead inbox second sweep (15 min)
- [ ] Repeat the 8:00 checks for the day's leads. Confirm every lead today has a human response logged.

### 4:30  EOD report (15 min)
- [ ] Post the EOD report in `#ops` (template below).
- [ ] Set tomorrow's first three tasks in Command.
- [ ] Hand off: anything Charles must do tonight is a direct Slack message, not buried in the report.

## Monthly checklist (first three business days unless noted)

- [ ] **33 Touch mailer and emails.** Export the `33-Touch` list, fill this month's email placeholders with current numbers (from the monthly market report), post for Charles's approval, schedule sends. Order the mailer with the mailing house by the 5th. Prepare the personal-note list with one prompt per person for Charles. `SOP-09`.
- [ ] **12 Direct postcard.** Export the `12-Direct` list, confirm the month's card design and stat with Charles, order by the 5th, log the QR campaign tag. `SOP-09`.
- [ ] **Scorecard month close.** Monthly totals row in `KPI Scorecard`; source breakdown; closed units and volume; database growth. Send to Charles before the first-Friday monthly meeting.
- [ ] **Review requests audit.** Every closing last month has a review request sent and a follow-up if none received. Testimonials sheet current; website testimonials section updated.
- [ ] **Database dedupe and audit.** Command: run the duplicate check; audit 50 random contacts for the one-type, one-relationship, one-source rule; fix; report the % in the scorecard.
- [ ] **SmartPlan audit.** Every `Met` contact is in `SP-33 Touch (Met)` or an active plan; every `Haven't Met` is in `SP-12 Direct (Haven't Met)` or `SP-Speed to Lead`; no contact is in two nurture plans.
- [ ] **Capital partners.** Monthly partner note (deals passed on and why) drafted via `CB Investor Analyst`, approved, sent. `Capital Partners` sheet reviewed for stale profiles.
- [ ] **Zapier health.** Task usage vs. plan limit; every Zap's last run date; reconnect anything expired (Meta, Google).
- [ ] **Marketing calendar.** Next month's non-listing social calendar drafted; market report template updated; one Loom SOP recorded for a task done more than twice this month.
- [ ] **Vendor list.** Confirm every name on the Homeowner's Vendor List is still active and recommended.
